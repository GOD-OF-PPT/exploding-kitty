```powershell
git diff --check
```

## 微信工具完成条件

构建完成后，以 `apps/minigame` 文档给出的路径执行微信开发者工具 CLI 导入。测试 AppID 只能证明工程结构和运行时兼容；真实登录、合法域名、分享和跨设备 Socket 必须使用正式 AppID 复核。

当前机器尚未取得微信开发者工具或真机截图证据，因此这些列没有被标记为通过；详情见 `apps/minigame/design-qa.md`。

## 外部环境完成条件

真实 PostgreSQL 运行时、迁移与重启恢复必须在可用 Docker daemon 或部署数据库上演练；当前机器未完成该项。正式验收还需要项目所有者提供 AppID/AppSecret、HTTPS/WSS 合法域名、TLS、生产 PostgreSQL、备案及合规配置。自动测试通过不能替代这些外部证据。

## 视觉完成条件

`prototype/audit/current/after/` 的 25 张 390 x 844 截图仅是设计基准。小游戏截图必须来自微信开发者工具或真机，再与同状态基准组合比较；所有 P0/P1/P2 修复后才能将小游戏视觉 QA 标记为通过。无法捕获真实小游戏截图时必须标为 blocked，不能复用 Web 截图冒充证据；当前证据状态见 `apps/minigame/design-qa.md`。
