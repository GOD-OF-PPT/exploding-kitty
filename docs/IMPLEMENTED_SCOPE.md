# 可运行实现范围

> 实现状态：2026-08-12 已完成本地完整切片；真实微信跨设备联网需下列生产配置。

本仓库将设计稿实现为一个可本地运行的完整游戏切片，并把平台相关能力放在可替换的 adapter seam 后面。

## 无需外部服务即可运行

- `original-2025@1` 56 张基础牌目录与 2–5 人开局配方；
- 当前玩家行动、连续出牌、抽牌、回合交接与淘汰判胜；
- 爆炸、拆弹和秘密插回；
- Attack 欠回合、Skip、Shuffle、See the Future、Favor；
- Nope 响应链、Pass、超时与奇偶结算；
- 两张/三张同名牌组合；
- 确定性机器人与全部本地房间流程；
- 房主明确开局与成员准备权限校验；默认本地加入流程由 Bot 模拟远端房主，在所有成员就绪后以房主身份开局；
- 当前玩家专属视图、行动记录、存档、恢复和幂等命令；
- 登录、建房、入房、准备、设置、教程、规则、断线和结算界面。
- 25 个 390 × 844 产品页面/状态的同状态视觉回归证据；设计画廊与审查夹具仅在开发环境加载。

## 平台 adapter

- `LocalGameSession`：浏览器内的权威本地对局，用于完整试玩和自动化测试；
- `RemoteGameSession`：面向远端权威服务器的序列、确认与恢复逻辑；
- `BrowserSessionRepository` / `MemorySessionRepository`：浏览器存档和测试存档；
- `WebSocketTransport` / `FakeTransport`：真实长连接和测试连接。

## 上线前仍需环境配置

下面能力需要项目所有者提供微信和服务器环境，因此本仓库只实现 adapter 与错误/恢复体验，不伪造生产凭证：

- 微信小游戏 AppID、登录 code 换服务端会话；
- 权威 WebSocket 服务地址、TLS、域名白名单；
- 云数据库/Redis 或自建事件存储；
- 实名、防沉迷、隐私协议与审核材料；
- 商业使用前的名称、商标、规则文本和美术授权结论。

正式部署时替换 composition root 的 session factory，React 界面与规则内核无需重写。
